Hammerspoon Keymap

hotkeys.json

Every hotkey on the Mac, laid out on the keyboard it lives on. Pick a modifier layer, click a key, change what it does.

This is the offline editor. An artifact is sandboxed away from your machine, so edits here are saved to this page, not applied to the live keyboard. Export hotkeys.json, drop it in ~/.hammerspoon, and press ⌘⌃⌥' to apply — no reload.

Select a key to see or change what it does.
Bindings are stored as { id, mods, key, description, action }. A call action names a function in the loaded Hammerspoon modules (WindowManager.applyLayout); an action hands off to HammerGhost's action system, which can run a shell command, publish MQTT or fire an HTTP request without any new Lua.
